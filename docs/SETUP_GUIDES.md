# PYQVerse Production Setup & Deployment Manual

## 1. MongoDB Atlas Setup
1. Create a free M0 or production cluster on [MongoDB Atlas](https://www.mongodb.com/cloud/atlas).
2. Under **Database Access**, create a user with `readWriteAnyDatabase` permissions on `pyqverse_production`.
3. Under **Network Access**, add IP whitelist entries (or `0.0.0.0/0` with strong password authentication for serverless runtimes).
4. Retrieve connection string: `mongodb+srv://<user>:<password>@cluster.mongodb.net/?retryWrites=true&w=majority`.
5. Add `MONGODB_URI` and `MONGODB_DATABASE` to your server environment.

## 2. Cloudflare R2 Object Storage
1. Go to Cloudflare Dashboard → **R2 Object Storage**.
2. Create bucket named `pyqverse-vault`.
3. Under **R2 API Tokens**, create a token with `Admin Read & Write` permissions scoped to the `pyqverse-vault` bucket.
4. Note your:
   - `CLOUDFLARE_ACCOUNT_ID`
   - `R2_ACCESS_KEY_ID`
   - `R2_SECRET_ACCESS_KEY`
   - `R2_ENDPOINT_URL` (format: `https://<accountid>.r2.cloudflarestorage.com`)
5. Keep bucket private; all uploads and downloads use short-lived signed URLs generated by the backend.

## 3. Google Apps Script Web App Deployment
1. Create a new Google Sheet named `PYQ Master Catalog`.
2. Open **Extensions → Apps Script**.
3. Copy code from `google-apps-script/Code.gs`.
4. Open **Project Settings → Script Properties** and add:
   - Property: `SHARED_SECRET`, Value: `<strong-random-key>`
5. Click **Deploy → New Deployment**:
   - Type: **Web App**
   - Execute as: **Me**
   - Who has access: **Anyone** (Requests are authenticated via `SHARED_SECRET` in JSON payload)
6. Copy Web App URL and add to `GOOGLE_APPS_SCRIPT_URL`.

## 4. Google Gemini & Groq AI Providers
1. Gemini:
   - Obtain API key from Google AI Studio.
   - Configure `GEMINI_API_KEY` in environment secrets.
   - Default model: `gemini-3.8-flash`.
2. Groq (Fallback):
   - Obtain API key from [Groq Console](https://console.groq.com).
   - Configure `GROQ_API_KEY`.
   - Default model: `llama-3.3-70b-versatile`.

## 5. Deployment Options
- **AI Studio / Full-Stack Node**: Runs full Express server (`server.ts`) with Vite dev server and persisted DB.
- **Frontend on Vercel**: Deploy repository to Vercel, build command `npm run build`, output directory `dist`.
- **Python Backend**: Deploy `/backend` to Cloud Run, Railway, or AWS ECS with `uvicorn app.main:app --host 0.0.0.0 --port 8000`.
